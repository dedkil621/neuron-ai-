# НЕЙРОН — Telegram AI bot

Telegram-бот на Python с Groq API и SQLite.

## Переменные окружения

Создайте секреты в настройках хостинга:

- `TELEGRAM_TOKEN` — новый токен Telegram-бота из @BotFather.
- `GROQ_API_KEY` — новый API-ключ Groq.
- `OWNER_ID` — числовой Telegram ID создателя (необязательно, но нужен для команд обучения).
- `DB_PATH` — путь к SQLite-файлу, если хостинг предоставляет постоянный диск (необязательно).

**Не вставляйте ключи в код и не публикуйте их в GitHub.** Если старые ключи отправлялись в чат или попадали в публичный репозиторий, отзовите их и создайте новые.

## Запуск

Python 3.10+:

```bash
pip install -r requirements.txt
python main.py
```

## Команды

- `/start` — запуск
- `/help` — помощь
- `/id` — показать Telegram ID
- `/reset` — очистить историю личного диалога
- `/teach вопрос | ответ` — добавить общее знание (только создатель)
- `/knowledge` — показать знания (только создатель)
- `/clear_knowledge` — очистить общую базу знаний (только создатель)

Для работы 24/7 нужен хостинг, который поддерживает постоянно работающие фоновые процессы. У бесплатных тарифов могут быть ограничения, сон сервиса или временная файловая система. Убедитесь, что SQLite-файл хранится на постоянном диске.
