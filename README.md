# НЕЙРОН — Telegram AI bot for FPS.ms

Бот работает в режиме long polling, который подходит для бесплатного Telegram Bot hosting на FPS.ms.

## Файлы
- `app.py` — основной код бота (FPS.ms запускает этот файл автоматически).
- `requirements.txt` — необходимые Python-библиотеки.
- `.env.example` — пример настроек без настоящих ключей.

## Настройка на FPS.ms

В панели сервера открой **Files** и создай файл `.env` в корневой папке. Скопируй туда:

```env
TELEGRAM_TOKEN=сюда_новый_токен_от_BotFather
GROQ_API_KEY=сюда_новый_ключ_Groq
OWNER_ID=сюда_числовой_Telegram_ID
```

Не загружай настоящий `.env` в GitHub и никому не отправляй ключи.

## Запуск
FPS.ms должен установить пакеты из `requirements.txt`, затем запустить `app.py`. В панели нажми **Start** в Console.

## Команды
- `/start` — начало
- `/help` — помощь
- `/id` — показать Telegram ID
- `/reset` — очистить личную историю
- `/teach вопрос | ответ` — добавить знание (только создатель)
- `/knowledge` — показать общую базу (только создатель)
- `/clear_knowledge` — очистить общую базу (только создатель)

Модель Groq: `openai/gpt-oss-120b`.
